Register a project to see its onboarding health

This dashboard evaluates candidate projects for ownership transfer using their Jira, GitHub, and Datadog signals. Paste any Jira board URL to add a new project.

Steps

  1. Open http://localhost:8000 in your browser
  2. Look for the search-box-style input at the top of the page (below the dark blue header). Placeholder text says "Paste a Jira URL or project key (e.g. TMT) — press Enter"
  3. Paste your Jira URL (e.g. https://celonis.atlassian.net/jira/software/c/projects/TMT/boards/721) into that input
  4. Press Enter, or click the blue Open → button on the right
  5. The dashboard extracts the project key (e.g. TMT) and opens that project's health page directly
Not seeing the input? Make sure you're on the landing page (URL is exactly http://localhost:8000 or http://localhost:8000/#/ — no #/project/... in the URL). If you're deep in a project's health page, click the ← All projects button in the top-right corner of the dark blue header to return to landing.
To register a NEW project (not just navigate): use the chat with me instead. Paste the Jira URL in the chat and say "add this to the onboarding dashboard". That runs the full register-onboarding-project skill — parses the URL, appends a new entry to projects.json, and runs service discovery. The dashboard input is only for jumping to an already-registered project.
